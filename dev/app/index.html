Secure WebUi Interface for Ollama

Chat with Ai, extract information from your documents, create presentations, miniapps, posters and much more...

Whatsapp and Wechat remote control enabled.

Requirements:

Ollama must be installed and running locally on it's (default) port 11434, make sure you have updated to the latest version.
