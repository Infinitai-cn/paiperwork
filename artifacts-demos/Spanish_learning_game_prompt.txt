Create a point and click game for students learning Spanish (Level A1), it should be a mystery game where following clues a mystery must be solved, game should have 5 different levels, each level must have 3 different clues to be solved. For backgrounds use an old wood building with several floors, use different themes for each floor, the game covers the full viewport.

IMPORTANT REQUIREMENTS:
1. Each clue card must display a custom SVG icon that is ALWAYS visible (no external images). Create unique SVG illustrations for each clue type (door, key, lamp, book, chair, window, bed, clock, closet, fridge, table, cup, treasure, photo, etc.).
2. Each level must have a unique animated SVG background that matches the theme (Entrance: floating keys/doors, Library: floating books/scrolls, Bedroom: floating moons/stars, Kitchen: floating utensils/steam, Attic: floating dust/sparkles).
3. SVG icons must be detailed and visually appealing with gold accent colors on dark backgrounds.
4. Include smooth CSS animations for the background SVGs (floating, pulsing, rotating effects).
5. At the start screen include a button labeled "Copiar Prompt del Juego" that copies the full prompt to clipboard.
6. Display the full prompt text on the start screen so users can see what was used to create the game.
7. Show a notification when the prompt is successfully copied.
8. Do NOT use any external images - pure SVG graphics only.

- Make sure the game follows Spanish learning grammar for CEFR level 1 (A1).
- 5 levels with different themed rooms (Ground Floor/Reception, Library, Bedroom, Kitchen, Attic).
- 3 clues per level with Spanish vocabulary questions (CEFR A1 level)
- Beautiful old wood aesthetic with animated SVG backgrounds
- Progress indicator showing current level
- Clue collection panel showing found clues with SVG thumbnails
- Modal popup for answering questions
- Win screen with score (no prompt on win screen)

VISUAL STYLE:

- Elegant typography (Cinzel for titles, Crimson Text for body)
